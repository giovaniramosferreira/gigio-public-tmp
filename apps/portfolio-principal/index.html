Sistemas em produção

Código aberto. Links vão para o repositório.

01.1 Next.js · Anthropic SDK · Supabase · Instagram Graph API

ViralPost

Pipeline que lê vídeos em alta no YouTube, extrai a tese com Claude e publica o carrossel resultante no Instagram — sem intervenção humana no ciclo.

Decisão

Teto de três vídeos por execução do cron.

Por quê

Transcrição e geração são as etapas caras. O limite mantém cada rodada dentro do timeout de serverless e torna o custo de API previsível por execução, em vez de proporcional ao que o YouTube devolver naquele dia.

Custo

Backlog cresce se o volume de tendência subir. Aceito: a tabela cron_runs registra cada rodada, então a fila é observável antes de virar problema.

01.2 Python · Flask · Apify · Anthropic SDK

Auraviz repo privado

Inteligência competitiva para padarias: coleta avaliações públicas, compara estabelecimentos vizinhos e gera relatório estratégico com IA.

Decisão

Repositório fechado, apesar do resto do portfólio ser aberto.

Por quê

A base de seed contém dados reais raspados do Google Maps — nome, endereço e telefone de estabelecimentos existentes. Publicar o repositório redistribuiria dado pessoal de terceiro coletado por scraping.

Custo

Perco o projeto como vitrine pública. Vale: a alternativa era reescrever o histórico do git para expor um pipeline cuja parte defensável é justamente a que eu não quero copiada.

01.3 Next.js · Prisma · Vitest

DarkTube OS

Console local-first para operar um canal de YouTube Shorts sobre os efeitos colaterais da IA — da descoberta de pauta ao pacote de exportação.

Decisão

Portões de originalidade antes da geração, não depois.

Por quê

Canal monetizado morre por conteúdo derivativo. Barrar a pauta repetida na entrada custa uma chamada; descobrir isso depois do vídeo pronto custa o vídeo inteiro — e, no limite, a monetização.

02

Como eu decido

i

Custo é requisito, não consequência

Chamada de LLM tem preço por token e teto de latência. Trato os dois como restrição de projeto desde o desenho — truncar transcrição em 8.000 caracteres é decisão de arquitetura, não otimização posterior.

ii

Todo processo autônomo deixa rastro

Se roda sem ninguém olhando, grava o que fez. Tabela de execuções, status, erro capturado. Sistema autônomo sem trilha não é automatizado — é opaco.

iii

Segredo fora do código, sempre

Varredura de histórico com gitleaks antes de qualquer repositório mudar de visibilidade. Encontrei os meus, rotacionei e movi para variável de ambiente — antes de abrir, não depois.

iv

Modelagem antes de modelo

Quinze anos em star schema e window function ensinam que a maior parte dos problemas ditos "de IA" é problema de dado mal estruturado. O LLM entra depois que o modelo de dados está de pé.
